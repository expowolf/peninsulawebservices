# Peninsula Web Services

Single-page marketing site for Peninsula Web Services — Sturgeon Bay, WI.

## Stack
- React 18 + Vite
- Tailwind CSS
- lucide-react icons

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Deploy
The `dist/` output is static — deploy to Vercel, Netlify, Cloudflare Pages, or any static host.
